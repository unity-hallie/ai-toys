## Design Principles Applied

**Bespoke vs Mass-Produced**
- Rejected: IKEA (flat), Ethan Allen (generic), West Elm (polished mass-market)
- Applied: Serif weight, proper spacing, print-ready, restraint in color
- Test: Does it add information or just visual noise?

**Educational Scaffolding**
- Level 2-3: Guided Discovery + Comparative Reasoning
- Users ask questions through tool selection
- Results include interpretation, not just numbers
- Stats explained inline (toggleable)
- Learns at own pace

**Substance Over Simulation**
- No glows, animations, rotations, fake mystery
- Substance from: serif typography + leading + margins + thick rules + single accent color
- Every interactive tool reveals something real
- Data, not decoration

## Key Insights

- Substance = rigor + honest design (not decoration)
- Educational tools should frame as questions, not features
- Single-file, self-contained tools maximize portability
- Teaching through guided discovery > feature overload
- Typography has weight—serif headers with proper leading feel substantial
